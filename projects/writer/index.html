Writer

小说编辑器 · 单文件网页版

Writer 是一个纯 HTML 单文件的小说写作工具：卷 / 章稿件树、人物与世界观资料库、 写作提示词面板、专注模式与排版控制。章节、资料、提示词与 AI 四个面板统一收在左侧一列， 中间与右侧全部留给了正文。正文自动保存在浏览器里，也可以随时导出 JSON 备份或导出纯文本。 不联网也能完整使用编辑与提示词功能。

数据只保存在本机浏览器里。清除站点数据、切换浏览器或更换访问地址都会看不到旧稿。 请定期用「导出 JSON」备份。
另外：用地址栏打开（Pages）与直接双击文件（file://）看到的是两份互不相通的数据， 因为浏览器按来源隔离存储；需要迁移时请用导出 / 导入。

功能

  • 卷 / 章稿件树：新增、重命名、排序、跨卷移动与删除；单章、单卷与全书字数实时统计。
  • 人物 / 设定资料库：人物、地点、世界观卡片，可一键引用进提示词。
  • 写作提示词面板：大纲、人设、场景、对白、伏笔、节奏、润色、扩写等模板，组合预览后一键复制。
  • 人称转换器：把当前章在第一人称（我）、第二人称（你）、第三人称（他 / 她 / 它）之间一键转换，可选是否保留心理描写。
  • AI 续写与润色：可接 DeepSeek 官方直连、本机代理或任意 OpenAI 兼容端点，也支持 Anthropic Messages 协议；流式输出，可随时停止。
  • 左侧单列布局：章节、资料、提示词、AI 四个面板共用左侧一列，正文独占其余宽度；窄屏下左栏收为抽屉。
  • 专注模式与排版：隐藏侧栏，字号、行高、字体与段首缩进可调。
  • 备份与导出：整包 JSON 导入导出、当前章或全书纯文本导出。
