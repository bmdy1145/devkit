A1_V_Φ8

A1 分支 · Φ8 主干。在 Φ7 基础上的增量修改，核心是全站响应式、多比例与触屏适配——viewport 增加 viewport-fit=cover，高度改 100dvh 并接入 env(safe-area-inset-*) 安全区；新增宽度断点 ≥1800 / ≤1024 / ≤820 / ≤560 与高度断点 ≤520，窄屏改为纵向堆叠、步骤列表横滑、顶栏两行图标化；触屏下放大热区并把输入控件与行号栏抬到 16px；分栏拖拽由 mouse 事件改为 pointer 事件。九款皮肤（基准 / 毛玻璃 / 霓虹 / 等宽 / 简约 / 材料设计 / 极简 / 高级质感 / Shadcn）共用同一套适配层，各自仅皮肤层不同，另均带第四层英文标识 Fix（跨风格同步缺陷修补）。九套皮肤各有两个先后版本：先出的 Fix 与随后的 Fix_Fix（集中修复 16 项缺陷与打磨项）；推荐使用 Fix_Fix。
